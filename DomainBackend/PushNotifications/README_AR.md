# إشعارات XSign Studio

تُرسل خدمة Firebase رسائل APNs للأجهزة التي سمحت بالإشعارات وسجلت رمزها. يُختار عنوان ونص حسب لغة XSign عند آخر تسجيل للجهاز. عند الضغط ينتقل المستخدم إلى بطاقة التطبيق، أو تفاصيل الدايلب، أو رابط HTTPS. جهّز التطبيق أو التعديل وانشره في الكتالوج قبل الإرسال.

## إعداد Apple

1. في Apple Developer فعّل Push Notifications على معرّف التطبيق المسجّل ضمن فريقك، وأنشئ مفتاح APNs. احتفظ بملف `.p8` ومعرّف المفتاح ومعرّف الفريق.
2. وقّع إصدار XSign الفعلي ببروفايل يدعم الإشعارات وبنفس معرّف الحزمة والفريق. تحقّق من أن توقيع التطبيق النهائي يحتوي على `aps-environment`. للبناء الذي يستعمل بروفايل تطوير اضبط `XSIGN_APS_ENVIRONMENT=development` وأرسل إلى `sandbox`. للتوزيع استعمل `production` في الاثنين.
3. بناء Studio العادي ينتج IPA يحتاج توقيع توزيع مناسب. إذا أعيد توقيعه بفريق مختلف أو ببروفايل بلا إشعارات، لن يسجّل مع خدمة هذا الإصدار. النسخ السابقة تحتاج تحديثًا يحتوي على دعم الإشعارات.

## إعداد الخدمة

1. أنشئ مشروع Firebase يدعم Cloud Functions وFirestore أو استخدم مشروعًا قائماً بصلاحية النشر. فعّل Firestore بوضع الإنتاج. أبقِ مجموعات `xsignPushDevices` و`xsignPushCampaigns` و`xsignPushBatches` مغلقة أمام العملاء المباشرين في Firestore؛ تتصل بها الخدمة وحدها عبر صلاحيات الخادم. عند وجود قاعدة تسمح بجميع المجموعات، استخدم مشروعًا مستقلاً أو قيّد قواعدها قبل التفعيل.
2. من هذا المجلد شغّل:

   ```bash
   npm --prefix functions install
   firebase functions:secrets:set XSIGN_PUSH_ADMIN_TOKEN --project PROJECT_ID
   firebase functions:secrets:set XSIGN_APNS_PRIVATE_KEY --data-file /path/to/AuthKey.p8 --project PROJECT_ID
   firebase deploy --only functions:xsign-push --project PROJECT_ID
   ```

   اجعل رمز المالك عشوائيًا بطول 32 حرفًا أو أكثر. عند النشر عيّن `XSIGN_APNS_BUNDLE` للبندل الفعلي، و`XSIGN_APNS_TEAM_ID` و`XSIGN_APNS_KEY_ID` من Apple، و`XSIGN_APNS_ENVIRONMENT` إلى `production` أو `sandbox` بحسب التوقيع. لا تضع المفتاح أو الرمز في المستودع.
3. في **نظرة عامة ← إشعارات XSign** أدخل عنوان الدالة المنتهي بـ`/push` وانشر إعدادات Studio. افتح النسخة الموقعة على الآيفون واسمح بالإشعارات حتى تسجّل الجهاز.
4. أدخل رمز المالك في Studio، اختر الوجهة، واملأ العنوان والنص بالعربية والإنجليزية والكردية، ثم راجع وأرسل الإشعار. زر **حالة الإرسال** يعرض الطلبات المقبولة لدى APNs والمتعذرة. قبول APNs لا يثبت أن المستخدم شاهد الإشعار.

تُحفظ لغة الجهاز ورمز APNs فقط في سجل التسجيل. لا يظهر رمز المالك داخل ملف إعدادات الجمهور، وتبقى المفاتيح في أسرار Firebase. خدمة الإشعارات مستقلة عن كتالوج XSign وعن مسار تثبيت IPA.
