# مراجعة الطلبات — XSign 1.0 الموحد

الحالة «كود جاهز» تعني أن التنفيذ موجود في الحزمة وYML، ولا تعني أن Xcode بُني أو أن iPhone ثبّت التطبيق. الملف المعتمد XSign_Full_Link.yml، والشرح التنفيذي XSign_Unified_Guide_AR.md.

استرجاع حساب GitHub المحظور، أو نشر موقع في حساب قديم دون صلاحية، أو التوقيع بشهادة غير صالحة، لا يمكن حله بوضع أوامر وهمية في YML. يحتفظ الملف بالأكواد المطلوبة ويذكر خطوات الصلاحية والشهادة الفعلية بدل إخفائها.

## معالجة الإخفاق الأخير ومحوّل متجر بلس

- عولجت التشخيصات العشرة في سجل 42290681355: شروط ToolbarContentBuilder في ثلاثة مواضع، وURL.path() مرتين، وView.bold()، ومعامل إحداثيات onTapGesture. وسع فحص iOS 15 ليشمل هذه الفئات في المشروع كله.
- يقبل محوّل متجر بلس الروابط المنشورة للصفوف المجانية الظاهرة حتى مع allow_ipa_download=false، ويحترم المخفي والمدفوع ويترك الصفوف بلا رابط دون تنزيل. لا يصنع روابط من التخزين ولا يتجاوز HTTP 401/403.
- صحح اسم وصورة المصدر حسب اللوحة وتصنيف Games، ولا يحجب كاش القرص التالف استجابة سليمة في الذاكرة. بقي المصدران بترتيبهما والبندل com.ipablack.xsign والإصدار 1.0.
- لا تتوفر ترجمة SDK محلية؛ نتيجة البناء بعد التصحيح تحتاج تشغيلاً جديداً، ونجاح تشغيل تاريخي أو فحص صياغة لا يثبت نجاح IPA الجديد.
