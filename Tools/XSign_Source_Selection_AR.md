# مصادر XSign المعتمدة — 2026-11-05

المصدر الأول:
https://supapi.trystore.net/rest/v1/plus_library_apps

أُزيلت موارد IPA BLACK القديمة وIPAOMTK والكتالوج المرجعي من التطبيق، وأزيل ملف IPAOMTK المنشور القديم.
قوائم المصادر القديمة، بما فيها المصادر المضافة سابقاً وإعدادات اللوحة المحفوظة، لا تستطيع إعادة أي مصدر غير معتمد إلى التحميل أو العرض.
تُحذف سجلات المصادر غير المعتمدة عند بدء التطبيق، وتُزال مجلدات كاش الكتالوج القديمة دون حذف التطبيقات المستوردة أو الموقعة أو الشهادات.
استُعملت أسماء مجلدات كاش جديدة لمنع ظهور محتويات قديمة ولو قبل اكتمال تنظيف الملفات في الخلفية.

السورس الثاني، بديل IPA BLACK القديم، هو https://raw.githubusercontent.com/ipablack/repo/main/repo.json. ملف GitHub الحالي فارغ (بايت واحد، سطر جديد) وليس JSON صالحاً؛ أُرفق repo.json مبدئي صحيح بقائمة تطبيقات فارغة. لم تُختلق تطبيقات أو روابط IPA.
خانة المالك في app_control.core_sources تحمل المعرف xsign.core.owned وعنوان المستودع الجديد. ينتقل قارئ إعدادات اللوحة إلى ملف السورس الجديد نفسه، ويترك كاش إعدادات اللوحة القديمة.
تُرفض بقية معرفات المصادر الواردة من إعدادات لوحة قديمة. يبقى المصدر الأساسي مثبتاً قبل خانة سورس المالك.

رجع طلب عينة من الواجهة HTTP 200 وقائمة REST، وتأكدت حقول id وname_ar وdownload_url وbundle_id وغيرها من صف حي. طلب لاحق لفحص التصفح رجع HTTP 403؛ توقف الفحص دون محاولة تجاوزه. لذلك لم نثبت إمكانية جلب جميع الصفحات من الخادم الحي. يظهر رفض الوصول بوضوح في التطبيق ولا يتحول إلى تحميل دائم أو خطأ AltStore مضلل.
المحول المحلي يحافظ على معرف البندل والإصدارات، ويفضل النص العربي المتاح، ويجلب الصفحات بترتيب id ثابت مع التحقق من Content-Range والعدد.
لا يُستبدل الكاش بقائمة جزئية عند فشل صفحة. الصفوف المخفية أو غير المسموح بتنزيلها أو التي تتطلب شراء لا تتحول إلى تنزيل مجاني.
لم يُختبر تنزيل IPA أو صلاحية جميع الروابط؛ HTTP 200 لا يثبت ذلك. البيانات لا تستخدم مفاتيح سرية أو تجاوزاً للمصادقة.

التعديلات لا تغيّر مسار التوقيع المحلي الذي طُبق سابقاً. البناء واختبارات Swift تحتاج تشغيل Actions المرفق على macOS.
الاختبارات المرفقة تستعمل كود سياسة المصادر والمحول الحقيقيين، وتتحقق من منع رجوع المصادر القديمة ومن خانة السورس المستقبلي وصيغة REST.
قارئ التطبيق جاهز لقراءة xsign_config من سورس المالك الجديد. واجهة لوحة التحكم وإدارة التطبيقات تُجهّز في الخطوة التالية. لم يُكتب إلى مستودع ipablack/repo مباشرة؛ يلزم رفع repo.json المرفق إلى جذره.
